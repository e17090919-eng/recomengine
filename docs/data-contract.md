# Data contract — canonical tables

_Generated by `recsys schema-doc` from `recsys_core.schema`; do not edit by hand._

All timestamps are **unix seconds, UTC**. Prices are in the market's local currency except `item.price_usd`. Customer-specific fields are mapped into these tables by the backfill tool (`configs/mappings/*.toml`) or the real-time `write` API.

## `user`

One row per shopper.

Primary key: `user_id`

| column | type | required | description | 说明 |
|---|---|---|---|---|
| `user_id` | string | ✔ | Stable member id (or device id for guests) | 会员 ID（访客用设备 ID） |
| `market` | string | ✔ | Home market code, e.g. CN-HAINAN | 所属市场代码 |
| `country` | string |  | ISO-3166 alpha-2 nationality | 国籍（ISO 两位码） |
| `language` | string |  | Preferred language (BCP-47 primary tag) | 偏好语言 |
| `member_level` | int64 |  | Loyalty tier, 0 = base | 会员等级，0 为普卡 |
| `register_ts` | int64 |  | Registration time, unix seconds UTC | 注册时间（UTC 秒） |
| `allowance_used` | float64 |  | Duty-free allowance used this period (local currency) | 本期已用免税额度（本币） |

## Event types

| event_type | meaning |
|---|---|
| `impression` | Item visible ≥50% for ≥1s (client-side, deduplicated per request) |
| `click` | Opened item detail |
| `favorite` | Added to wishlist |
| `add_cart` | Added to cart |
| `order_submit` | Order placed (not yet paid) |
| `purchase` | Payment succeeded |
| `dislike` | Explicit negative feedback ('not interested') |
| `share` | Shared item |
| `search` | Search result click (item_id = clicked item) |

Unregistered event types are rejected by ingest and counted by the quality gate.
